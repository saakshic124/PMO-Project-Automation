Project Summary Builder

Any files → a reviewable draft → one Confluence page

Step 1 · Source files

Drop any project files (SOW, order form, dealbook, notes — anything). Claude reads them and drafts a summary you can review below before anything is published. This is AI extraction, not guaranteed-accurate OCR — it can misread a number or a name on messy or unusual documents, so check the draft against the source before publishing.

Self-hosted. This calls this app's own backend, which holds your real Anthropic API key and Confluence credentials server-side — neither ever reaches this page or your browser.
