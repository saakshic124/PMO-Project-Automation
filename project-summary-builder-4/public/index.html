Or — any files, straight to Confluence, via your Claude API

Drop any project files (SOW, order form, dealbook, notes — anything). Claude reads them and creates a multi-page Confluence project space directly using your Atlassian connector — one click, no intermediate review step. This is still AI extraction, not guaranteed-accurate OCR — it can misread a number or a name on messy or unusual documents, so check the created pages (linked below once done) against the source documents.

Self-hosted. This calls /api/draft and /api/publish on this app's own backend, which holds your real Anthropic API key server-side — the key never reaches this page or your browser. See README.md to run or deploy the server.
