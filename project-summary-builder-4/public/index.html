Project Summary Builder

Any files → one Confluence page, via Claude

Drop any project files (SOW, order form, dealbook, notes — anything). Claude reads them and creates one Confluence page directly — one click, no intermediate review step. This is still AI extraction, not guaranteed-accurate OCR — it can misread a number or a name on messy or unusual documents, so check the created page (linked below once done) against the source documents.

Self-hosted. This calls /api/publish-page on this app's own backend, which holds your real Anthropic API key and Confluence credentials server-side — neither ever reaches this page or your browser.
